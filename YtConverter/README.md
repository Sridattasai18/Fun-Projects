# YtConverter 🎬

A modern, beautiful YouTube video and audio downloader built with Flask and pytubefix. Features a stunning gradient UI with glassmorphism effects.

![Python](https://img.shields.io/badge/Python-3.12+-blue.svg)
![Flask](https://img.shields.io/badge/Flask-3.0+-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

## ✨ Features

- 🎥 **High-Quality Video Downloads** - Download YouTube videos in the highest available resolution
- 🎵 **Audio Extraction** - Extract audio and save as MP3 format
- 🎨 **Modern UI** - Beautiful gradient design with purple, pink, and blue colors
- ✨ **Glassmorphism Effects** - Premium glass-morphic design elements
- 🔄 **Auto Cleanup** - Downloaded files are automatically deleted after serving
- ⚡ **Fast & Efficient** - Powered by pytubefix for reliable downloads
- 🛡️ **URL Validation** - Validates YouTube URLs before processing
- 📱 **Responsive Design** - Works seamlessly across all devices

## 🚀 Quick Start

### Prerequisites

- Python 3.8 or higher
- pip package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sridattasai18/Fun-Projects.git
   cd Fun-Projects/YtConverter
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**
   ```bash
   python app.py
   ```

4. **Open your browser**
   Navigate to `http://127.0.0.1:5000`

## 🎯 Usage

1. **Visit the landing page** - See the beautiful gradient design
2. **Click "Start Converting"** - Navigate to the converter form
3. **Paste YouTube URL** - Enter the video link you want to download
4. **Select format** - Choose between MP4 (video) or MP3 (audio)
5. **Click "Convert Now"** - View video preview and download button
6. **Download** - Click the download button to save your file

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **Download Engine**: pytubefix
- **Frontend**: HTML5, CSS3 (Vanilla)
- **Design**: Glassmorphism, Gradient effects
