Fun Projects

A collection of small, interactive, and experimental web projects I build when I’m bored, curious, or just want to try something new.

Sometimes I use AI to explore ideas faster. Sometimes I code everything myself to see what happens. This repo is basically my playground for testing concepts, animations, interactions, and small tools that solve tiny problems in my daily life.

I don’t aim for perfection here. The goal is simple: learn, experiment, and have fun while building.

Projects
1. 3D Antigravity Project

An interactive hand-controlled particle experiment inspired by a scene from Iron Man 2 where Tony Stark manipulates particles to form a new element.

Uses the webcam to detect hand and finger movement

Particles react to the finger position

Designed as a fun, futuristic interaction experiment

2. Heart Trail Animation

A tiny visual project that creates a trail of hearts following the mouse cursor.

Hearts appear wherever the cursor moves

Simple animation experiment

Built just for fun and visual effect

3. MarkTabs (Browser Extension)

A small browser extension made to solve a real problem.

Sometimes I open too many tabs and forget why I opened them. Instead of closing them and later needing them again, MarkTabs lets me mark important tabs so I can come back to them later.

Mark important tabs

Avoid losing useful pages

Built as a simple productivity helper
