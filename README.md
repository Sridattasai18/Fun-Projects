# Fun Projects 🚀

A collection of small, interactive, and experimental web projects I build when I'm bored, curious, or just want to try something new.

Sometimes I use AI to explore ideas faster. Sometimes I code everything myself to see what happens. This repo is basically my playground for testing concepts, animations, interactions, and small tools that solve tiny problems in my daily life.

I don't aim for perfection here. The goal is simple: **learn, experiment, and have fun while building**.

## 📂 Projects

### 1. [3D Antigravity Project](./3D-Antigravity-Project)
**An interactive hand-controlled particle experiment inspired by Iron Man 2**

<img src="https://img.shields.io/badge/Three.js-000000?style=flat&logo=three.js&logoColor=white" alt="Three.js"/> <img src="https://img.shields.io/badge/MediaPipe-4285F4?style=flat&logo=google&logoColor=white" alt="MediaPipe"/> <img src="https://img.shields.io/badge/WebGL-990000?style=flat&logo=webgl&logoColor=white" alt="WebGL"/>

**Features:**
- 🎥 Uses webcam to detect hand and finger movements via MediaPipe
- ✨ 5,000 particles react to finger position in real-time
- 🎨 Multiple particle shapes (Sphere, Galaxy, DNA, Cube, etc.)
- 🖐️ Hand gestures control rotation, zoom, and particle attraction
- ⚡ High-performance rendering with Three.js BufferGeometry

**Tech Stack:** Three.js, MediaPipe Hands, JavaScript, HTML5, CSS3

**How to Run:**
```bash
cd 3D-Antigravity-Project
# Open index.html in a modern browser (Chrome/Edge recommended)
# Allow webcam access when prompted
```

### 3. [YtConverter](./YtConverter) 🎬
**A modern YouTube video and audio downloader with a stunning gradient UI**

<img src="https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white" alt="Python"/> <img src="https://img.shields.io/badge/Flask-000000?style=flat&logo=flask&logoColor=white" alt="Flask"/> <img src="https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white" alt="HTML5"/>

**Features:**
- 🎥 Download YouTube videos in highest available resolution
- 🎵 Extract audio and save as MP3 format
- 🎨 Beautiful glassmorphism UI with gradient effects
- 🔄 Auto cleanup of downloaded files
- ⚡ Fast and efficient with pytubefix
- 🛡️ URL validation before processing
- 📱 Fully responsive design

**Tech Stack:** Python, Flask, pytubefix, HTML5, CSS3

**How to Run:**
```bash
cd YtConverter
pip install -r requirements.txt
python app.py
# Visit http://127.0.0.1:5000 in your browser
```

**⚠️ Disclaimer:** For educational purposes only. Respect YouTube's Terms of Service and copyright laws.

### 4. [markTabs](./markTabs) 📝
**A browser extension to add notes to your tabs**

<img src="https://img.shields.io/badge/Chrome-4285F4?style=flat&logo=googlechrome&logoColor=white" alt="Chrome"/> <img src="https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black" alt="JavaScript"/>

**Features:**
- 📌 Mark important tabs with custom notes
- 💾 Persistent storage using Chrome Storage API
- 🔍 Never forget why you opened a tab
- ✏️ Edit or delete notes anytime
- 🎨 Clean, minimal UI

**Tech Stack:** JavaScript, Chrome Extension API (Manifest V3), HTML5, CSS3

**How to Install:**
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the `markTabs` folder
5. The extension is now ready to use!

**Browser Extensions:**
- Chrome Extension API (Manifest V3)

- Web APIs (Canvas, WebGL, MediaDevices)
